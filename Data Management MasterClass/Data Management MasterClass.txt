types of data:
Within an organization's data holdings, there are typically four different types of data, each serving a different function. These types of data include: 

Master Data (dimension table data)
Transactional Data (fact table data)
Reference Data (subset of master data - like country code, language etc)
Freeform Data

for explanations: https://www.data-sentinel.com/resources/the-four-types-of-data

In essence: Master data defines the "what" (e.g., customer, product), while reference data defines the "how" (e.g., state, currency) it's categorized.

Mean, Median and Mode :
Mean is used when there is no outliers
Median should be used when there is outliers
Mode is to get the most repeated value
Range - Maximum - Minimum (More the range is, more the deviation and you have to go with Median, if negative number exists, range could be higher than maximum value)
Standard Deviation: How far is the dataset deviate from the average. For eg: in real estate, it can help to understand, how much the price of a house could deviate from other houses on an average
